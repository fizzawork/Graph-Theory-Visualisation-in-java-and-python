Project Title: Graph Theory visualisations via multiple languages
Project Team Size: 2
Course: Graph Theory
Language: Java, Python

Problem: Job Assignment
Consider a scenario where there are N job applicants and M job positions available. Each job applicant has a set of skills, and each job position requires a specific set of skills. We want to find the best possible matching of applicants to positions such that each job position is filled, and applicants are assigned to positions based on their skills.

Solution: Optimised Job Assignment
The Max. Bipartite Matching provides an optimal assignment of job applicants to positions, ensuring that each position is filled with a suitable candidate.

Problem: Transportation Network
Consider a transportation network with multiple sources (e.g., factories) and sinks (e.g., distribution centres or cities). The goal is to optimize the flow of goods from sources to sinks, taking into account the capacities of the edges (roads, pipelines, etc.) connecting them.

Solution: Transportation Network Optimisation
The Max. Flow Methods provide an optimal distribution of goods from sources to sinks, ensuring that the transportation network operates at maximum efficiency.

Methodology:

Bipartiteness Check
Enabling the feature to visualise Maximum Bipartite Matching.
Calculate Maximised Flow of any  weighted graph using Edmond-Karp Algorithm(Python)
& Ford-Fulkerson Algorithm(Java)
